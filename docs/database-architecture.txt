## PHILOSOPHY: Design Once, Use Gradually

✓ Create ALL tables on Day 1 (plugin activation)
✓ Use only MVP tables initially
✓ PRO tables exist but remain empty until licensed
✓ No schema changes between tiers - only usage changes
✓ Forward-compatible, backward-stable

1. DATABASE VERSIONING SYSTEM
═══════════════════════════════════════════════════════════════════════════════

**Version Tracking Table:**

```sql
CREATE TABLE {prefix}_hms_db_version (
    id INT PRIMARY KEY AUTO_INCREMENT,
    version VARCHAR(10) NOT NULL,
    applied_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    description TEXT,
    INDEX idx_version (version)
```

All tables created at version 1.0.0, even if not used until later.

Legend:

───────────────────────────────────────────────────────────────────────────────
TABLE 1: PATIENTS [MVP] ✓ CRITICAL
───────────────────────────────────────────────────────────────────────────────

CREATE TABLE {prefix}_hms_patients (
    -- Primary Key
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    
    -- Unique Identifiers
    patient_id VARCHAR(20) UNIQUE NOT NULL COMMENT 'HOS-2026-0001',
    barcode VARCHAR(50) UNIQUE COMMENT 'For smart ID cards [PRO-S]',
    
    -- Basic Demographics [MVP]
    first_name VARCHAR(100) NOT NULL,
    last_name VARCHAR(100) NOT NULL,
    date_of_birth DATE NOT NULL,
    gender ENUM('male', 'female', 'other') NOT NULL,
    blood_group VARCHAR(10),
    
    -- Contact Information [MVP]
    phone VARCHAR(20) NOT NULL,
    email VARCHAR(100),
    address TEXT,
    emergency_contact VARCHAR(20),
    emergency_name VARCHAR(100),
    
    -- Metadata
    registration_date DATETIME DEFAULT CURRENT_TIMESTAMP,
    photo_url VARCHAR(255) COMMENT 'Patient photo [PRO-S]',
    notes TEXT,
    status ENUM('active', 'inactive', 'anonymized') DEFAULT 'active',
    
    -- Audit [ALL]
    created_by BIGINT UNSIGNED COMMENT 'Staff ID who registered',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    -- Indexes for Performance
    INDEX idx_patient_id (patient_id),
    INDEX idx_phone (phone),
    INDEX idx_status (status),
    INDEX idx_registration_date (registration_date),
    INDEX idx_created_by (created_by),
    FULLTEXT idx_name (first_name, last_name)
    
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
COMMENT='Core patient records - Used from MVP';

-- Estimated rows at scale: 10,000 - 50,000
-- Critical indexes: patient_id (unique lookups), phone (search), name (FULLTEXT)

TABLE 4: APPOINTMENTS [MVP] ✓ CRITICAL
───────────────────────────────────────────────────────────────────────────────

CREATE TABLE {prefix}_hms_appointments (
    -- Primary Key
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    
    -- Unique Identifier
    appointment_id VARCHAR(20) UNIQUE NOT NULL COMMENT 'APT-2026-0001',
    
    -- Core Fields [MVP]
    patient_id BIGINT UNSIGNED NOT NULL,
    doctor_id BIGINT UNSIGNED NOT NULL,
    appointment_date DATE NOT NULL,
    appointment_time TIME NOT NULL,
    duration INT DEFAULT 15 COMMENT 'Minutes',

    status ENUM('scheduled', 'confirmed', 'completed', 'cancelled', 'no_show') DEFAULT 'scheduled',

    notes TEXT,
    
    -- Billing [MVP]
    consultation_fee DECIMAL(10, 2),

    -- Recurring Appointments [PRO-B]

    recurrence_pattern VARCHAR(50) COMMENT 'weekly, monthly, etc [PRO-B]',
    recurrence_parent_id BIGINT UNSIGNED COMMENT 'If this is recurring instance',
    
    -- Audit [ALL]
    created_by BIGINT UNSIGNED COMMENT 'Who booked',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    -- Foreign Keys
    FOREIGN KEY (patient_id) REFERENCES {prefix}_hms_patients(id) ON DELETE RESTRICT,
    
    -- Performance Indexes
    INDEX idx_appointment_id (appointment_id),
    INDEX idx_doctor_date (doctor_id, appointment_date),
    INDEX idx_patient (patient_id),
    INDEX idx_status (status),
    INDEX idx_payment_status (payment_status),
    INDEX idx_date_time (appointment_date, appointment_time)
    
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
COMMENT='OPD appointments - MVP core feature';

-- Estimated rows: 50,000 - 500,000 per year
-- Critical query: doctor_date index for schedule view

4. OPTIMIZATION STRATEGIES
═══════════════════════════════════════════════════════════════════════════════

**A. Indexing Strategy:**

Critical indexes (MUST HAVE):
1. All foreign keys (for JOIN performance)
2. Frequently filtered columns (status, dates, patient_id)
3. UNIQUE indexes on ID fields (patient_id, invoice_id, etc.)
4. Composite indexes for common query patterns:
   - (doctor_id, appointment_date) for schedule view
   - (patient_id, status) for patient records
   - (patient_id, payment_status) for dues

**B. Query Optimization:**

1. **Use prepared statements everywhere** (security + performance)
2. **Fetch only needed columns** (avoid SELECT *)
3. **Pagination** (LIMIT + OFFSET for large result sets)
4. **COUNT optimization** (use COUNT(*) with LIMIT when possible)

Example optimized query:
```sql
-- BAD (no index usage)
SELECT * FROM {prefix}_hms_appointments 
WHERE DATE_FORMAT(appointment_date, '%Y-%m') = '2026-01';

-- GOOD (uses index)
SELECT id, patient_id, doctor_id, appointment_date, status
FROM {prefix}_hms_appointments 
WHERE appointment_date >= '2026-01-01' AND appointment_date < '2026-02-01'
ORDER BY appointment_date ASC
LIMIT 50 OFFSET 0;
```

**C. Caching Strategy:**

```php
// Cache expensive queries
function get_today_appointments($doctor_id) {
    $cache_key = 'hms_today_appts_' . $doctor_id . '_' . date('Y-m-d');
    $cached = get_transient($cache_key);
    
    if ($cached !== false) {
        return $cached;
    }
    
    // Expensive query
    $appointments = /* DB query */;
    
    // Cache for 1 hour
    set_transient($cache_key, $appointments, HOUR_IN_SECONDS);
    
    return $appointments;
}
```

Cache candidates:
- Today's appointments (1-hour TTL)
- Lab test catalog (1-day TTL)
- Medicine database (1-day TTL)
- Bed availability (15-min TTL)
- Report aggregates (6-hour TTL)

**D. Table Partitioning (Future):**

When audit_log exceeds 1 million rows:
```sql
ALTER TABLE {prefix}_hms_audit_log 
PARTITION BY RANGE (YEAR(created_at)) (
    PARTITION p2026 VALUES LESS THAN (2027),
    PARTITION p2027 VALUES LESS THAN (2028),
    PARTITION p2028 VALUES LESS THAN (2029)
);
```

**E. Archive Strategy:**

Automated monthly cron job:
```php
// Archive old audit logs
function archive_old_audit_logs() {
    global $wpdb;
    
    $retention_days = get_tier_retention_days(); // 30, 90, 365, or unlimited
    
    if ($retention_days === PHP_INT_MAX) {
        return; // Enterprise - no archival
    }
    
    // Move to archive table
    $wpdb->query($wpdb->prepare(
        "INSERT INTO {$wpdb->prefix}hms_audit_log_archive 
         SELECT * FROM {$wpdb->prefix}hms_audit_log 
         WHERE created_at < DATE_SUB(NOW(), INTERVAL %d DAY)",
        $retention_days
    ));
    
    // Delete from main table
    $wpdb->query($wpdb->prepare(
        "DELETE FROM {$wpdb->prefix}hms_audit_log 
         WHERE created_at < DATE_SUB(NOW(), INTERVAL %d DAY)",
        $retention_days
    ));
}
```

```php
            $this->get_lab_catalog_table_sql(),

            $this->get_prescriptions_table_sql(),
            $this->get_invoices_table_sql(),
            $this->get_payments_table_sql(),
            $this->get_medicines_table_sql(),
            $this->get_staff_table_sql(),
            $this->get_attendance_table_sql(),
            $this->get_audit_log_table_sql(),
            $this->get_error_log_table_sql(),
            $this->get_db_version_table_sql(),
        ];
        
        foreach ($tables as $sql) {

        }
        
        // Record version

    }

     * Get patients table SQL
     */
    private function get_patients_table_sql() {
        $table_name = $this->wpdb->prefix . 'hms_patients';
        
        return "CREATE TABLE {$table_name} (
            id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
            patient_id VARCHAR(20) UNIQUE NOT NULL,
            barcode VARCHAR(50) UNIQUE,
            first_name VARCHAR(100) NOT NULL,
            last_name VARCHAR(100) NOT NULL,
            date_of_birth DATE NOT NULL,
            gender ENUM('male', 'female', 'other') NOT NULL,
            blood_group VARCHAR(10),
            phone VARCHAR(20) NOT NULL,
            email VARCHAR(100),
            address TEXT,
            emergency_contact VARCHAR(20),
            emergency_name VARCHAR(100),
            registration_date DATETIME DEFAULT CURRENT_TIMESTAMP,
            photo_url VARCHAR(255),
            notes TEXT,
            status ENUM('active', 'inactive', 'anonymized') DEFAULT 'active',
            created_by BIGINT UNSIGNED,

        ) {$this->charset_collate};";

    // ... other table methods ...
    
    /**
     * Record database version
     */
    private function record_version($version, $description) {
        $table = $this->wpdb->prefix . 'hms_db_version';
        
        $this->wpdb->insert($table, [
            'version' => $version,
            'description' => $description,
            'applied_at' => current_time('mysql')
        ]);
        
        update_option('hms_db_version', $version);
    }
    
    /**
     * Check if migration needed
     */
    public function needs_migration() {
        $installed_version = get_option('hms_db_version', '0.0.0');
        return version_compare($installed_version, $this->current_version, '<');
    }
    
    /**
     * Run migrations
     */
    public function migrate() {
        $installed_version = get_option('hms_db_version', '0.0.0');
        
        // Example future migration
        if (version_compare($installed_version, '1.1.0', '<')) {
            $this->migrate_to_1_1_0();
        }
        
        if (version_compare($installed_version, '2.0.0', '<')) {
            $this->migrate_to_2_0_0();
        }
    }
    
    /**
     * Example migration method
     */
    private function migrate_to_1_1_0() {
        // Add new column example
        $table = $this->wpdb->prefix . 'hms_patients';
        
        $column_exists = $this->wpdb->get_results(
            "SHOW COLUMNS FROM {$table} LIKE 'whatsapp_number'"
        );
        
        if (empty($column_exists)) {
            $this->wpdb->query(
                "ALTER TABLE {$table} ADD COLUMN whatsapp_number VARCHAR(20) AFTER phone"
            );
        }
        
        $this->record_version('1.1.0', 'Added WhatsApp number field');
    }
}
```
