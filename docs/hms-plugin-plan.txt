
### Hospital Management System (HMS) Plugin
## WordPress-Based Complete Hospital Solution

**Target Environment:** WordPress 6.0+  
**PHP Version:** 7.4+  
**Primary Tech Stack:** PHP, React 18+, REST API  
**Development Approach:** Modern, Scalable, Maintainable

---

## 1. EXECUTIVE SUMMARY

### Plugin Purpose
A comprehensive Hospital Management System designed for small to medium hospitals (like the target hospital with 4 doctors, 8 beds, OT facility, and lab services). The system manages the complete patient journey from registration through treatment to billing, with strong emphasis on financial tracking and due management.

### Target Hospital Profile
- **Medical Staff:** 4 Doctors (including Gynecology specialist)
- **Support Staff:** Nurses, Manager, Receptionist, Lab Assistant, Guard
- **Facilities:** 
  - 3 Private Cabins + 1 Ward (5 beds) = 8 total beds
  - 1 Operation Theatre (Gynecology focus)
  - Laboratory with pathology & USG
  - Medicine store room (internal use, not commercial pharmacy)
  - 4 Doctor chambers

### Key Differentiators
1. **Integrated Due Management** - Track and manage patient dues across all departments
2. **Digital Signature System** - Every transaction tracked with responsible staff signature
3. **Simplified Pharmacy** - Internal medicine store (no retail operations)
4. **Gynecology OT Focus** - Specialized OT management for surgical procedures
5. **Biometric Integration** - Attendance tracking for staff accountability

### 2.3 Internationalization (i18n) Implementation

**Translation Workflow:**

1. **Text Domain Setup** (in main plugin file):
```php
// wphelpzone-hms.php
load_plugin_textdomain('wphelpzone-hms', false, dirname(plugin_basename(__FILE__)) . '/languages');
```

2. **All User-Facing Strings Must be Translatable:**
```php
// PHP Translation functions
__('Patient registered successfully', 'wphelpzone-hms');           // Returns translated string
_e('Total Amount', 'wphelpzone-hms');                              // Echo translated string
_n('1 patient', '%s patients', $count, 'wphelpzone-hms');         // Plural
esc_html__('Dashboard', 'wphelpzone-hms');                         // Translated + escaped
esc_attr__('Search patients', 'wphelpzone-hms');                   // For attributes

// JavaScript (React) Translation
import { __ } from '@wordpress/i18n';

const title = __('Patient Registration', 'wphelpzone-hms');
const message = sprintf(
    __('Patient %s has been registered', 'wphelpzone-hms'),
    patientName
);
```

3. **Generate Translation Template (.pot file):**
```bash
# Using WP-CLI
wp i18n make-pot . languages/wphelpzone-hms.pot

# Or using Poedit to scan all PHP/JS files
```

4. **Create Language-Specific Files:**
- **Bengali**: `wphelpzone-hms-bn_BD.po` (editable)
- Compile to: `wphelpzone-hms-bn_BD.mo` (binary)

**Example Translations (Bengali):**
```po
msgid "Patient registered successfully"
msgstr "রোগী সফলভাবে নিবন্ধিত হয়েছে"

msgid "Total Amount"
msgstr "মোট পরিমাণ"

msgid "Due Amount"
msgstr "বকেয়া পরিমাণ"

msgid "Doctor"
msgstr "ডাক্তার"
```

**Supported Languages (Initial):**
- English (en_US) - Default
- Bengali (bn_BD) - Bangladesh
- Hindi (hi_IN) - India (future)
- Arabic (ar) - Middle East countries (future)

## 3. DATABASE SCHEMA

### 3.1 Core Tables

#### Patients Table
```sql
CREATE TABLE {prefix}_hms_patients (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    patient_id VARCHAR(20) UNIQUE NOT NULL,        -- HOS-2026-0001
    barcode VARCHAR(50) UNIQUE,                     -- For smart ID cards
    first_name VARCHAR(100) NOT NULL,
    last_name VARCHAR(100) NOT NULL,
    date_of_birth DATE NOT NULL,
    gender ENUM('male', 'female', 'other') NOT NULL,
    blood_group VARCHAR(10),
    phone VARCHAR(20) NOT NULL,
    email VARCHAR(100),
    address TEXT,
    emergency_contact VARCHAR(20),
    emergency_name VARCHAR(100),
    registration_date DATETIME DEFAULT CURRENT_TIMESTAMP,
    photo_url VARCHAR(255),
    notes TEXT,
    status ENUM('active', 'inactive') DEFAULT 'active',
    created_by BIGINT UNSIGNED,                     -- Staff signature
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_patient_id (patient_id),
    INDEX idx_phone (phone),
    INDEX idx_status (status),
    INDEX idx_registration_date (registration_date),
    FULLTEXT idx_name (first_name, last_name)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

#### Medical History Table

### 3.2 Database Performance Considerations

**Indexing Strategy:**
- Primary keys on all `id` columns
- Unique indexes on all ID fields (patient_id, invoice_id, etc.)
- Composite indexes on frequently queried column combinations
- Foreign keys with proper CASCADE rules
- Full-text indexes for name searches

**Optimization:**
- Hash-based lookups for O(1) complexity where possible
- Prepared statements for all queries (security + performance)
- JSON columns for flexible data (medicines in prescription, line items in invoice)
- Proper normalization to avoid data duplication

**Caching Strategy:**
```php
// Cache frequently accessed data using WordPress Transients
public function get_hospital_settings() {
    $cached = get_transient('hms_hospital_settings');
    if ($cached !== false) return $cached;
    
    $settings = /* fetch from DB */;
    set_transient('hms_hospital_settings', $settings, HOUR_IN_SECONDS);
    return $settings;
}

// Cache test catalog (rarely changes)
public function get_test_catalog() {
    $cached = wp_cache_get('hms_test_catalog', 'hms');
    if ($cached !== false) return $cached;
    
    $tests = /* fetch from DB */;
    wp_cache_set('hms_test_catalog', $tests, 'hms', DAY_IN_SECONDS);
    return $tests;
}

// Cache doctor schedules for current day
public function get_doctor_schedule($doctor_id, $date) {
    $cache_key = 'hms_doctor_schedule_' . $doctor_id . '_' . $date;
    $cached = get_transient($cache_key);
    if ($cached !== false) return $cached;
    
    $schedule = /* fetch from DB */;
    set_transient($cache_key, $schedule, 6 * HOUR_IN_SECONDS);
    return $schedule;
}
```

**Cache Invalidation Strategy:**
- Delete relevant transients on data update
- Use WordPress object cache for session-level caching
- Implement cache warmup for dashboard stats

**Audit Log Management:**
```sql
-- Partition audit log table by year for better performance
CREATE TABLE {prefix}_hms_audit_log_2026 LIKE {prefix}_hms_audit_log;

-- Archive old audit logs (automated monthly cron job)
-- Move records older than 1 year to archive table
INSERT INTO {prefix}_hms_audit_log_archive 
SELECT * FROM {prefix}_hms_audit_log 
WHERE created_at < DATE_SUB(NOW(), INTERVAL 1 YEAR);

DELETE FROM {prefix}_hms_audit_log 
WHERE created_at < DATE_SUB(NOW(), INTERVAL 1 YEAR);
```

**Archive Strategy:**
- Keep current year in main table for fast access
- Archive previous years for compliance (7-year retention)
- Compress archived data (gzip)
- Provide search interface for archived records

### 4.12 Digital Signature & Audit System (CRITICAL)

**Purpose:**
Every transaction must be traceable to the responsible staff member. This creates accountability and prevents disputes.

**What Gets Signed:**
1. **Invoices** - Issued by (receptionist/manager)
2. **Receipts** - Received by (receptionist/manager)
3. **Prescriptions** - Prescribed by (doctor)
4. **Lab Results** - Verified by (lab assistant/doctor)
5. **Admissions** - Admitted by (manager/receptionist)
6. **Discharges** - Discharged by (doctor/manager)
7. **Medicine Dispensing** - Dispensed by (pharmacist/nurse)
8. **Salary Payments** - Paid by (manager)
9. **Salary Slips** - Issued by (manager)

**Digital Signature Implementation:**

```php
namespace WPHelpZone\HMS\Security;

class DigitalSignature {
    
    /**
     * Sign a transaction
     */
    public function sign_transaction(string $action, string $entity_type, int $entity_id, array $data): void {
        global $wpdb;
        
        $current_user = wp_get_current_user();
        $table = $wpdb->prefix . 'hms_audit_log';
        
        $wpdb->insert($table, [
            'user_id' => $current_user->ID,
            'action' => sanitize_text_field($action),
            'entity_type' => sanitize_text_field($entity_type),
            'entity_id' => absint($entity_id),
            'new_data' => wp_json_encode($data),
            'ip_address' => $this->get_client_ip(),
            'user_agent' => sanitize_text_field($_SERVER['HTTP_USER_AGENT'] ?? ''),
            'created_at' => current_time('mysql')
        ]);
    }
    
    /**
     * Get signature details for display
     */
    public function get_signature(string $entity_type, int $entity_id): array {
        global $wpdb;
        $table = $wpdb->prefix . 'hms_audit_log';
        
        $signature = $wpdb->get_row($wpdb->prepare(
            "SELECT * FROM {$table} WHERE entity_type = %s AND entity_id = %d ORDER BY created_at DESC LIMIT 1",
            $entity_type,
            $entity_id
        ), ARRAY_A);
        
        if ($signature) {
            $user = get_userdata($signature['user_id']);
            $signature['user_name'] = $user ? $user->display_name : 'Unknown';
            $signature['user_role'] = $user ? implode(', ', $user->roles) : 'Unknown';
        }
        
        return $signature ?: [];
    }
}
```

```php
namespace WPHelpZone\HMS\Core;

class BackupManager {
    
    /**
     * Automated daily database backup
     */
    public function schedule_daily_backup() {
        if (!wp_next_scheduled('hms_daily_backup')) {
            wp_schedule_event(strtotime('02:00:00'), 'daily', 'hms_daily_backup');
        }
        add_action('hms_daily_backup', [$this, 'create_database_backup']);
    }
    
    /**
     * Create database backup (SQL dump)
     */
    public function create_database_backup() {
        global $wpdb;
        
        $tables = $wpdb->get_results("SHOW TABLES LIKE '{$wpdb->prefix}hms_%'", ARRAY_N);
        $backup_content = '';
        
        foreach ($tables as $table) {
            $table_name = $table[0];
            $backup_content .= $this->export_table($table_name);
        }
        
        // Save to wp-content/backups/hms/
        $backup_dir = WP_CONTENT_DIR . '/backups/hms/';
        wp_mkdir_p($backup_dir);
        
        $filename = 'hms_backup_' . date('Y-m-d_H-i-s') . '.sql';
        file_put_contents($backup_dir . $filename, $backup_content);
        
        // Compress
        $this->compress_backup($backup_dir . $filename);
        
        // Upload to cloud (optional)
        $this->upload_to_cloud($backup_dir . $filename . '.gz');
        
        // Delete backups older than 30 days
        $this->cleanup_old_backups($backup_dir, 30);
    }
    
    /**
     * Upload to cloud storage (S3, Google Drive, Dropbox)
     */
    public function upload_to_cloud($file_path) {
        $cloud_provider = get_option('hms_backup_cloud_provider'); // 's3', 'dropbox', 'gdrive'
        
        switch ($cloud_provider) {
            case 's3':
                // Use AWS SDK
                $s3 = new Aws\S3\S3Client([...]);
                $s3->putObject([
                    'Bucket' => get_option('hms_s3_bucket'),
                    'Key' => basename($file_path),
                    'SourceFile' => $file_path
                ]);
                break;
                
            case 'dropbox':
                // Use Dropbox API
                break;
                
            case 'gdrive':
                // Use Google Drive API
                break;
        }
    }
    
    /**
     * One-click restore from backup
     */
    public function restore_from_backup($backup_file) {
        global $wpdb;
        
        // Decompress if needed
        if (substr($backup_file, -3) === '.gz') {
            $backup_file = $this->decompress_backup($backup_file);
        }
        
        // Read SQL file
        $sql = file_get_contents($backup_file);
        
        // Execute SQL (split by semicolon)
        $queries = explode(';', $sql);
        foreach ($queries as $query) {
            if (trim($query)) {
                $wpdb->query($query);
            }
        }
        
        return true;
    }
}

            'permission_callback' => function() {
                // Only admin can delete
                return current_user_can('delete_records');
            }
        ]);
    }
}
```

### 6.3 Data Encryption

**Sensitive Field Encryption:**
```php
namespace WPHelpZone\HMS\Security;

class DataEncryption {
    
    private $encryption_key;
    
    public function __construct() {
        // Use WordPress salt or custom key stored securely
        $this->encryption_key = defined('HMS_ENCRYPTION_KEY') 
            ? HMS_ENCRYPTION_KEY 
            : wp_salt('auth');
    }
    
    /**
     * Encrypt sensitive data (medical history, diagnosis)
     */
    public function encrypt(string $data): string {
        $iv = openssl_random_pseudo_bytes(16);
        $encrypted = openssl_encrypt(
            $data, 
            'AES-256-CBC', 
            $this->encryption_key, 
            0, 
            $iv
        );
        return base64_encode($iv . $encrypted);
    }
    
    /**
     * Decrypt sensitive data
     */
    public function decrypt(string $encrypted_data): string {
        $data = base64_decode($encrypted_data);
        $iv = substr($data, 0, 16);
        $encrypted = substr($data, 16);
        
        return openssl_decrypt(
            $encrypted, 
            'AES-256-CBC', 
            $this->encryption_key, 
            0, 
            $iv
        );
    }
}

// Usage in PatientManager
public function save_medical_history($patient_id, $diagnosis) {
    $encryption = new DataEncryption();
    $encrypted_diagnosis = $encryption->encrypt($diagnosis);
    
    // Save encrypted data
    $wpdb->insert($table, [
        'patient_id' => $patient_id,
        'diagnosis' => $encrypted_diagnosis  // Encrypted
    ]);
}
```

**Fields to Encrypt:**
- Medical history details

- Surgery notes
- Prescription details (optional)
- Lab test results (sensitive)

### 6.5 Data Breach Response Plan

**If patient data is compromised:**
1. **Immediate**: Disable affected accounts, reset passwords
2. **Within 24 hours**: Notify admin/chairman
3. **Within 72 hours**: Notify affected patients (if email/phone compromised)
4. **Document**: Log breach in audit system
5. **Remediate**: Fix security vulnerability
6. **Review**: Security audit and penetration testing

### Custom Hook Example (usePatients)

```javascript
// assets/src/hooks/usePatients.js
import { useState, useEffect } from '@wordpress/element';
import apiFetch from '@wordpress/api-fetch';

export function usePatients() {
    const [patients, setPatients] = useState([]);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);

    const fetchPatients = async () => {
        try {
            setLoading(true);
            const data = await apiFetch({ path: '/hms/v1/patients' });
            setPatients(data);
            setError(null);
        } catch (err) {
            setError(err.message);
        } finally {
            setLoading(false);
        }
    };

    const createPatient = async (patientData) => {
        try {
            const newPatient = await apiFetch({
                path: '/hms/v1/patients',
                method: 'POST',
                data: patientData
            });
            setPatients(prev => [...prev, newPatient]);
            return { success: true, data: newPatient };
        } catch (err) {
            return { success: false, error: err.message };
        }
    };

    const updatePatient = async (id, patientData) => {
        try {
            const updated = await apiFetch({
                path: `/hms/v1/patients/${id}`,
                method: 'PUT',
                data: patientData
            });
            setPatients(prev => prev.map(p => p.id === id ? updated : p));
            return { success: true, data: updated };
        } catch (err) {
            return { success: false, error: err.message };
        }
    };

    const deletePatient = async (id) => {
        try {
            await apiFetch({
                path: `/hms/v1/patients/${id}`,
                method: 'DELETE'
            });
            setPatients(prev => prev.filter(p => p.id !== id));
            return { success: true };
        } catch (err) {
            return { success: false, error: err.message };
        }
    };

    const searchPatients = async (query) => {
        try {
            setLoading(true);
            const data = await apiFetch({ path: `/hms/v1/patients/search?q=${query}` });
            setPatients(data);
        } catch (err) {
            setError(err.message);
        } finally {
            setLoading(false);
        }
    };

    useEffect(() => {
        fetchPatients();
    }, []);

    return {
        patients,
        loading,
        error,
        fetchPatients,
        createPatient,
        updatePatient,
        deletePatient,
        searchPatients
    };
}

## 10. ERROR HANDLING & LOGGING

### 10.1 Frontend Error Boundaries

```javascript
// assets/src/components/common/ErrorBoundary.js
import React from 'react';
import apiFetch from '@wordpress/api-fetch';

class ErrorBoundary extends React.Component {
    constructor(props) {
        super(props);
        this.state = { hasError: false, error: null };
    }

    static getDerivedStateFromError(error) {
        return { hasError: true, error };
    }

    componentDidCatch(error, errorInfo) {
        // Log to server
        apiFetch({
            path: '/hms/v1/logs/error',
            method: 'POST',
            data: {
                message: error.toString(),
                stack: error.stack,
                componentStack: errorInfo.componentStack,
                url: window.location.href,
                timestamp: new Date().toISOString()
            }
        }).catch(console.error);
    }

    render() {
        if (this.state.hasError) {
            return (
                <div className="error-container">
                    <h2>Something went wrong</h2>
                    <p>We've been notified and will fix this soon.</p>
                    <button onClick={() => window.location.reload()}>
                        Reload Page
                    </button>
                </div>
            );
        }

        return this.props.children;
    }
}

export default ErrorBoundary;

// Usage in App.js
import ErrorBoundary from './components/common/ErrorBoundary';

function App() {
    return (
        <ErrorBoundary>
            <Layout>
                <Routes>...</Routes>
            </Layout>
        </ErrorBoundary>
    );
}
```

### 10.2 Backend Error Logging

```php
namespace WPHelpZone\\HMS\\Core;

class ErrorLogger {
    
    /**
     * Log error to database
     */
    public function log_error($level, $message, $context = []) {
        global $wpdb;
        
        $table = $wpdb->prefix . 'hms_error_log';
        
        $wpdb->insert($table, [
            'level' => $level, // 'error', 'warning', 'info'
            'message' => $message,
            'context' => wp_json_encode($context),
            'user_id' => get_current_user_id(),
            'ip_address' => $_SERVER['REMOTE_ADDR'] ?? '',
            'user_agent' => $_SERVER['HTTP_USER_AGENT'] ?? '',
            'url' => $_SERVER['REQUEST_URI'] ?? '',
            'created_at' => current_time('mysql')
        ]);
        
        // Also log to WordPress debug.log if enabled
        if (WP_DEBUG && WP_DEBUG_LOG) {
            error_log("HMS [{$level}]: {$message} " . wp_json_encode($context));
        }
    }
    
    /**
     * Log critical errors and send notification
     */
    public function log_critical($message, $context = []) {
        $this->log_error('critical', $message, $context);
        
        // Send email to admin
        $admin_email = get_option('admin_email');
        wp_mail(
            $admin_email,
            'HMS Critical Error',
            "A critical error occurred in HMS:\n\n{$message}\n\nContext: " . print_r($context, true)
        );
    }
}
```

class CSVImporter {
    public function import_patients($csv_file) {
        $csv = fopen($csv_file, 'r');
        $header = fgetcsv($csv); // First row as column names
        
        $imported = 0;
        $errors = [];
        
        while (($row = fgetcsv($csv)) !== false) {
            $patient_data = array_combine($header, $row);
            
            // Validate
            $validator = new PatientValidator();
            if (!$validator->validate($patient_data)) {
                $errors[] = "Row {$imported}: " . $validator->get_errors();
                continue;
            }
            
            // Import
            $patient_manager = new PatientManager();
            $patient_manager->create($patient_data);
            $imported++;
        }
        
        fclose($csv);
        
        return [
            'imported' => $imported,
            'errors' => $errors
        ];
    }
}
